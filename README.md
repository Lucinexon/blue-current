# Blue Current

An interactive, responsive ocean-conservation landing page. Explore six major ocean threats through clickable fish, evidence-backed explainers, practical solutions, and a personal action checklist.

## Run locally

No build step or dependencies are required. Open `index.html` in a modern browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy to GitHub Pages

1. Push this project to a GitHub repository on the `main` branch.
2. Open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source.
3. Push to `main`; the included workflow publishes the site automatically.

## Features

- Animated underwater scene and responsive layout
- Six clickable fish / issue explainers
- Research links for ocean pollution, coral heat stress, overfishing, acidification, deoxygenation, and lost fishing gear
- Conservation action checklist that builds a personal plan
- No external runtime libraries, build tools, or image assets

## Research notes

The page links to its underlying research sources and labels estimates by scope. The figures are a dated snapshot, not a live data feed; check the cited source pages for updates before reusing statistics elsewhere.
